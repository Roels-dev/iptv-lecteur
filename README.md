# IPTV Lecteur

Lecteur IPTV Android (téléphone + TV Android) : chaînes gratuites et légales (iptv-org, Free-TV),
rubriques Sport et Apprendre l'anglais, codes d'accès uniques par appareil.

- **Télécharger l'APK** : https://github.com/Roels-dev/iptv-lecteur/releases/latest/download/IPTV-Lecteur.apk
- **Gérer les codes d'accès** : voir `supabase/GERER-LES-CODES.md`
- **Modifier la liste Apprendre l'anglais** : `playlists/anglais.m3u` (sans recompiler)

Chaque push sur `main` compile et publie automatiquement un nouvel APK (GitHub Actions).

Version actuelle : 2.0 (codes d'accès).
